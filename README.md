# Customer Analysis using SQL

A beginner-friendly SQL project built using MySQL to analyze customer registrations by city and registration date.
## Project Objective

The objective of this project is to analyze customer registration data using SQL and extract useful insights based on city and registration date.
## Tools Used

- MySQL
- MySQL Workbench
- SQL
- GitHub
- ## Dataset

The project uses a sample customer dataset containing:

- Customer ID
- Name
- Phone Number
- Email
- City
- Registration Date

The dataset contains 10 customers from Vizag, Hyderabad, and Chennai.
## SQL Analysis

The project includes SQL queries to:

- View all customers
- Count customers by city
- Analyze monthly registrations
- Sort cities by customer count
- Find customers registered after a specific date
- Classify customers as Local or Other City
- Find the latest registered customer
- Analyze city-wise registrations after March 1
- Generate an overall project summary

## Key SQL Concepts

- WHERE
- GROUP BY
- ORDER BY
- COUNT
- DISTINCT
- MONTHNAME
- CASE
- MIN
- MAX
- LIMIT
